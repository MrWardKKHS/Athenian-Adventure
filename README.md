# Python Adventure: From Basics to Storytelling
## Welcome to Your Python Journey! 🐍🏛️

This repository is designed to help you learn Python step by step, starting with the basics and culminating in an interactive Choose Your Own Adventure game set in Ancient Greece!
📖 Learning Path

    Introduction to Python
        Printing text (print())
        Variables and data types
        User input (input())

    Making Decisions
        Conditionals (if, elif, else)
        Boolean logic

    Loops & Repetition
        while loops
        for loops

    Collections
        Lists ([])
        Dictionaries ({})

    Building the Adventure Game
        Structuring a text-based game
        Handling user choices
        Using a simple inventory system

📝 Instructions

    Clone this repository

    git clone https://github.com/YOUR-ORG/YOUR-REPO.git
    cd YOUR-REPO

    Work through the exercises in order, completing each Python file.

    Modify and expand your Choose Your Own Adventure game using what you've learned!

📜 Final Challenge: "Escape from Athens"

Your final task will be to create an interactive text-based adventure set in Ancient Greece. You'll use your Python skills to build a game where the player must make decisions, avoid danger, and escape to safety!
💡 Need Help?

If you're stuck, check the hints in each exercise file or ask for help in our class discussion forum.

Good luck, and have fun coding your own adventure! 🎭🔥
